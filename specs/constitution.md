
# StudyTrack Project Constitution

**Project:** StudyTrack – Student Study Planner  
**Team:** WDD 430 Team 02  
**Version:** 1.0 (Draft)

## 1. Project Purpose
StudyTrack helps students organize assignments, schedule study sessions, monitor deadlines, and track academic progress through a simple web application.

## 2. Development Principles

### I. Student-Centered Design
The application must be easy to understand, navigate, and use. Students should be able to manage academic tasks without unnecessary complexity.

### II. Code Quality
The project will use Next.js App Router, TypeScript, and Tailwind CSS. Code must be readable, reusable, maintainable, and follow agreed formatting standards.

### III. Accessibility and Responsiveness
The application must support mobile and desktop devices, accessible forms, keyboard navigation, and readable text.

### IV. Security and Privacy
Students must only access their own private records. User input must be validated, authentication must protect personal data, and secrets must never be committed to GitHub.

### V. Team Collaboration
Each development task should be tracked using GitHub issues. Team members must use feature branches, submit pull requests, and obtain at least one teammate's review before merging into main.

### VI. Testing and Quality Assurance
Each feature must have measurable acceptance criteria. Changes must be tested and checked for errors before merging.

## 3. Technology Standards
- Framework: Next.js App Router
- Language: TypeScript
- Styling: Tailwind CSS
- Database: To be decided by the team
- Authentication: To be decided by the team
- Hosting: To be decided by the team

## 4. Minimum Viable Product
The first version will support:
1. Student registration, login, and logout.
2. Assignment creation, viewing, editing, and deletion.
3. Study session scheduling and management.
4. Upcoming deadline tracking.
5. Assignment completion and progress tracking.

## 5. Governance
Changes to project principles or major requirements must be reviewed by the team. The constitution will guide development decisions and code reviews.
